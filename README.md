# Proyek 74: Reader Mode Toggle (Pratinjau Mode Baca Nyaman)

Proyek ini adalah aplikasi web interaktif yang mensimulasikan fitur **Reader Mode** pada browser web modern menggunakan **HTML5, CSS3, dan Vanilla JavaScript**. Proyek ini membantu siswa pemula memahami cara memanipulasi properti CSS via JavaScript untuk kenyamanan membaca pengguna (accessibility/UI UX).
